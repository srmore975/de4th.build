Step 3 — YouTube upload notifier

Posts an embed to a channel whenever your channel uploads a new video. Works while the app is open.

How it works

  • Uses YouTube's public RSS feed — no API key needed.
  • First run sets a baseline (no spam from old videos).
  • Remembers the last announced video, so nothing posts twice.
  • The app must stay open while you want notifications to fire.
